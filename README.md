# Island for Windows: downloads

Installers for **Island**, the animated activity pill for the top of your Windows screen.

Island needs a licence key. Get it on Whop: https://whop.com/almost-intelligent/island-c0/

1. Download **Island-Setup.exe** from the [latest release](https://github.com/yusufmj2005/island-releases/releases/latest).
2. Run it. If Windows shows "Windows protected your PC", click **More info → Run anyway** (the installer isn't code-signed yet).
3. When Island asks, paste the licence key from your Whop order and click **Activate**.

To update, download the newest installer and run it over the old one. Your settings and licence are kept.

This repository holds installers only; Island's source code is private.
